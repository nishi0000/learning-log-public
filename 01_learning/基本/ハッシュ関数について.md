-  トピック：ハッシュ関数 `h(x)=x mod n` の意味
    
    - 何を扱った：
        
        - 問題文に出てくるハッシュ関数
            
        - `h(x)=x mod n` の具体的な読み方
            
    - 結論：
        
        - `h(x)=x mod n` ＝ キー x を n で割った余りを求める
            
        - その結果が「何番の箱に入れるか」を表す
            
        - 例として、`n=10` のとき

-  トピック：衝突の意味
    
    - 何を扱った：
        
        - 「衝突」とは何か
            
        - 問題文でいう「キーaとbが衝突する条件」
            
    - 結論：
        
        - 衝突 ＝ 違うデータなのに同じ箱に入ろうとすること
            
        - 問題文では、`h(a)` と `h(b)` が同じなら衝突
            
        - 例：
            
            - `n=10`
                
            - `13 mod 10 = 3`
                
            - `23 mod 10 = 3`
                
            - よって 13 と 23 は衝突
                
    - 覚えるもの：
        
        - 衝突 ＝ 違うキーなのに同じハッシュ値になること
            
        - 条件：`h(a)=h(b)`
            
-  トピック：衝突条件の式
    
    - 何を扱った：
        
        - 問題の核心である「任意のキーaとbが衝突する条件」
            
        - 余りと差の関係
            
    - 結論：
        
        - 衝突する条件は `a mod n = b mod n`
            
        - 同じ余りになる数の差は n の倍数になる
            
        - 例：
            
            - `n=5`
                
            - `12 mod 5 = 2`
                
            - `17 mod 5 = 2`
                
            - よって 12 と 17 は衝突
                
            - 差は `17 - 12 = 5`
                
        - この問題での正解として、
            
            - `a-b が n の倍数`  
                が示された
                
    - 覚えるもの：
        
        - `a mod n = b mod n`
            
        - `a-b が n の倍数`
