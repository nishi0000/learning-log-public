### 0. スレッド概要

- 扱ったテーマ：IDS（侵入検知システム）の意味と役割、IPSとの違い
    

### 1. 扱ったトピック一覧（時系列）

-  トピック：IDSとは何か
    
    - 何を扱った：
        
        - 「IDSってなんですか」という質問
            
        - IDSの正式名称と意味
            
    - 結論：
        
        - IDS = Intrusion Detection System
            
        - 読み方：アイディーエス
            
        - 日本語：侵入検知システム
            
        - 意味：ネットワークやサーバを監視して、怪しい通信や不正アクセスの兆候を見つける仕組み
            
    - 覚えるもの：
        
        - IDS = Intrusion Detection System = 侵入検知システム
            
        - IDSは「不正侵入を検知する仕組み」
            
-  トピック：IDSが検知するもの
    
    - 何を扱った：
        
        - IDSがどのような不審な動きを検知するか
            
    - 結論：
        
        - IDSは以下のようなものを検知する
            
            - 外部から大量にアクセスされている
                
            - 通常とは違う通信パターンがある
                
            - 既知の攻撃パターンに似た通信がある
                
            - サーバ内で不審な操作が行われている
                
    - 覚えるもの：
        
        - IDSは、怪しい通信や不正アクセスの兆候を見つける
            
-  トピック：IDSの基本動作
    
    - 何を扱った：
        
        - IDSが検知後に何をするか
            
    - 結論：
        
        - IDSの基本的な流れ：
            
            ```text
            怪しい通信を見つける
            ↓
            管理者に通知する
            ↓
            ログに記録する
            ```
            
        - IDSは基本的に「検知する」ための仕組み
            
    - 覚えるもの：
        
        - IDSは「見つける」「通知する」「ログに記録する」役割
            
-  トピック：IDSとIPSの違い
    
    - 何を扱った：
        
        - IDSとIPSの役割の違い
            
    - 結論：
        
        - IDS：不正侵入を検知する
            
        - IPS：不正侵入を検知して防御・遮断する
            
        - 遮断まで行うものはIDSではなくIPSと呼ばれる
            
    - 覚えるもの：
        
        ```text
        IDS：見つける係
        IPS：止める係
        ```
        
-  トピック：IDS / IPSの略語の覚え方
    
    - 何を扱った：
        
        - DとPの意味
            
    - 結論：
        
        - D = Detection = 検知
            
        - P = Prevention = 防止
            
    - 覚えるもの：
        
        ```text
        IDS = Detection = 検知
        IPS = Prevention = 防止
        ```
