### 1. 扱ったトピック一覧（時系列）

-  トピック：IDS の略称確認
    
    - 何を扱った：
        
        - URL `https://www.fe-siken.com/kakomon/30_aki/q42.html` の問題を前提に、「IDSってなんのりゃく？」を確認
            
        - IDS のフルスペル、読み方、意味を確認
            
    - 結論：
        
        - IDS → Intrusion Detection System → アイディーエス → 不正侵入検知システム
            
        - 「不正侵入を見つけて知らせる仕組み」として扱った
            
    - 覚えるもの：
        
        - IDS = Intrusion Detection System
            
        - D = Detection = 検知
            
        - 意味は「不正侵入検知システム」
            
-  トピック：IPS と IDS の違い
    
    - 何を扱った：
        
        - 「IPS? IDS??」という確認
            
        - IDS と IPS の役割差を比較
            
    - 結論：
        
        - IDS → Intrusion Detection System → アイディーエス → 不正侵入検知システム
            
            - 怪しい通信や攻撃を見つける
                
            - 基本は止めない
                
        - IPS → Intrusion Prevention System → アイピーエス → 不正侵入防御システム
            
            - 怪しい通信や攻撃を見つけて止める
                
        - このスレッド内では、
            
            - IDS は「見つけて知らせる」
                
            - IPS は「見つけて遮断する」  
                として整理した
                
    - 覚えるもの：
        
        - IDS = 検知
            
        - IPS = 防止 / 遮断
            
        - D = Detection
            
        - P = Prevention
            
-  トピック：IDS / IPS は何なのか（機械か、システムか）
    
    - 何を扱った：
        
        - 「そもそも、なに？？機械？システム？？」という確認
            
        - IDS / IPS が物理機器そのものかどうかを整理
            
    - 結論：
        
        - 機械そのものの名前ではなく、仕組み・製品カテゴリの名前として整理した
            
        - 専用の機械であることもある
            
        - ソフトウェアであることもある
            
        - ファイアウォールなどの機能の一部であることもある
            
        - このスレッドでは「不正アクセスを見つけたり、防いだりするためのシステム」として確定した
            
        - まとめとして「ネットワークを見張る警備システム」と表現した
            
    - 覚えるもの：
        
        - IDS / IPS は「機械そのもの」ではなく「監視・検知・防御のためのシステム」
            
        - IDS = 見つけるシステム
            
        - IPS = 見つけて止めるシステム
            
-  トピック：ファイアウォール、IDS / IPS、WAF の違い
    
    - 何を扱った：
        
        - 「ふぁいあうぉーるとか、WAF？とかとどうちがうの？」という確認
            
        - ファイアウォール、IDS / IPS、WAF の役割差を整理
            
    - 結論：
        
        - ファイアウォール
            
            - 通信の出入りを制限する
                
            - IPアドレス、ポート番号、プロトコルなどをもとに通すか止めるかを決める
                
            - このスレッドでは「入口でふるい分ける」「門番」と整理した
                
        - IDS / IPS
            
            - 通信の中身や挙動を見て攻撃らしさを検知する
                
            - IDS は見つけて知らせる
                
            - IPS は見つけて止める
                
        - WAF → Web Application Firewall → ワフ
            
            - Webアプリ向けの防御
                
            - HTTP / HTTPS の中身を見て守る
                
            - SQLインジェクション、XSS、悪意ある入力などの Web アプリ向け攻撃を防ぐものとして扱った
                
        - このスレッドでは役割を次のように整理した
            
            - ファイアウォール：「この通信、入っていい？」
                
            - IDS / IPS：「この通信、怪しくない？」
                
            - WAF：「このWebへのリクエスト、危なくない？」
                
    - 覚えるもの：
        
        - ファイアウォール：IP / ポートで通信制御
            
        - IDS：不正侵入を検知
            
        - IPS：不正侵入を検知して遮断
            
        - WAF = Web Application Firewall = Webアプリへの攻撃を防御
