### 1. 扱ったトピック一覧（時系列）

-  トピック：C#のジェネリック引数とは？
    
    - 何を扱った：
        
        - 「ジェネリック引数」という用語の意味（`List<int>` の `int`、`Dictionary<string,int>` の `string`/`int`）
            
        - ジェネリック型／ジェネリックメソッドに対して「型」を渡す概念
            
    - 結論：
        
        - ジェネリック引数 = ジェネリック型（またはメソッド）に渡す「型」
            
        - 例：`List<int>` の `int`、`Box<string>` の `string`、`FirstOrDefault<int>(...)` の `int`
            
        - 用語整理：
            
            - `T` / `TKey` / `TValue` = 型パラメータ（型を表す“変数”）
                
            - `List<int>` の `int` = 型引数（ジェネリック引数）（実際に入れる型）
                
    - 覚えるもの：
        
        - 「ジェネリック引数（型引数）＝実際に指定する型」「型パラメータ＝Tなどの型変数」の区別
            
        - 具体例：`List<int>` の `int` がジェネリック引数
