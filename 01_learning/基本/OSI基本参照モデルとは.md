-  トピック：OSI基本参照モデルの7階層
    
    - 何を扱った：
        
        - OSI基本参照モデルの7つの階層名と役割を確認した。
            
    - 結論：
        
        - 第7層：アプリケーション層
            
            - 利用者に近い通信機能を担当する。
                
            - Web、メールなどが該当する。
                
        - 第6層：プレゼンテーション層
            
            - データ形式の変換、文字コード、暗号化などを担当する。
                
        - 第5層：セッション層
            
            - 通信の開始・維持・終了を管理する。
                
        - 第4層：トランスポート層
            
            - 相手まで正しく届ける役割を持つ。
                
            - TCP、UDPなどが該当する。
                
        - 第3層：ネットワーク層
            
            - 宛先までの経路を決める。
                
            - IPなどが該当する。
                
        - 第2層：データリンク層
            
            - 同じネットワーク内で機器同士をつなぐ。
                
            - MACアドレスなどが該当する。
                
        - 第1層：物理層
            
            - ケーブル、電気信号、無線などを扱う。
                
    - 覚えるもの：
        
        - 第7層：アプリケーション層
            
        - 第6層：プレゼンテーション層
            
        - 第5層：セッション層
            
        - 第4層：トランスポート層
            
        - 第3層：ネットワーク層
            
        - 第2層：データリンク層
            
        - 第1層：物理層

-  トピック：Webサイトを見るときのOSI階層の例
    
    - 何を扱った：
        
        - Webサイトを見るとき、各階層がどのように関係するかを確認した。
            
    - 結論：
        
        - アプリケーション層：HTTPでWebページを要求する。
            
        - トランスポート層：TCPでデータを確実に届ける。
            
        - ネットワーク層：IPアドレスを使って宛先まで届ける。
            
        - データリンク層：MACアドレスで同じネットワーク内の機器に届ける。
            
        - 物理層：LANケーブルやWi-Fiで信号を送る。
            
    - 覚えるもの：
        
        - Webを見るときも、通信処理は階層ごとに役割分担されている。

    - 何を扱った：

    - 結論：

        - TCP / UDP：トランスポート層
            
        - IP / ICMP：ネットワーク層

        - ケーブル / 電気信号 / 無線：物理層

-  トピック：略語・用語
    
    - 何を扱った：
        
        - このスレッドで出てきた略語と対応階層を確認した。
            
    - 結論：
        
        - OSI → Open Systems Interconnection → オーエスアイ → 通信機能を7階層に分けて整理する考え方
            
        - TCP → Transmission Control Protocol → ティーシーピー → データを相手まで正しく届けるための通信方式。OSI第4層。
            
        - UDP → User Datagram Protocol → ユーディーピー → TCPと同じくトランスポート層に属する通信方式。OSI第4層。
            
        - IP → Internet Protocol → アイピー → 宛先までの経路を決めて届けるための通信方式。OSI第3層。
            
        - ICMP → Internet Control Message Protocol → アイシーエムピー → ネットワーク層に属する通信制御用のプロトコル。OSI第3層。
            
        - HTTP → HyperText Transfer Protocol → エイチティーティーピー → Webページの要求・応答に使うプロトコル。OSI第7層。
            
        - SMTP → Simple Mail Transfer Protocol → エスエムティーピー → メール送信に関係するプロトコル。OSI第7層。
            
        - DNS → Domain Name System → ディーエヌエス → 名前解決に関係する仕組み。OSI第7層。
            
        - SSL/TLS → Secure Sockets Layer / Transport Layer Security → エスエスエル／ティーエルエス → 暗号化通信に関係する仕組み。プレゼンテーション層寄りとして扱われることがある。
            
        - MACアドレス → Media Access Control Address → マックアドレス → 同じネットワーク内で機器を識別するアドレス。OSI第2層。
            
    - 覚えるもの：
        
        - TCP：第4層
            
        - IP：第3層
            
        - MACアドレス：第2層
            
        - HTTP / SMTP / DNS：第7層
