### 1. 扱ったトピック一覧（時系列）

-  トピック：TCPパケット
    
    - 何を扱った：
        
        - 「TCPパケットとは何か」を確認した。
            
        - 厳密には「TCPパケット」より **TCPセグメント** と呼ぶことが多いことを確認した。
            
    - 結論：
        
        - TCPパケットとは、TCP通信でネットワーク上を流れるデータの小さなかたまり。
            
        - TCPで通信するとき、大きなデータは小分けされて送られる。
            
        - TCPパケットには、宛先ポート番号、送信元ポート番号、順番の番号、確認応答の番号、制御フラグ、実際のデータなどが含まれる。
            
        - TCPは、届いたか確認しながら、順番どおりに、確実に届けようとする通信方式。
            
    - 覚えるもの：
        
        - **TCPパケット = TCPで確実に届けるための管理情報つき小包**
            
        - **TCPパケット = TCP通信で使われる、順序管理や到達確認のための情報を持ったデータのかたまり**
            
        - 正確には **TCPセグメント** と呼ぶことが多い。
            
-  トピック：TCP
    
    - 何を扱った：
        
        - 「TCPとは何か」を確認した。
            
    - 結論：
        
        - **TCP → Transmission Control Protocol → ティーシーピー → 確実性を重視した通信プロトコル**
            
        - TCPは、ネットワークでデータを送るときのルールの1つ。
            
        - TCPは、相手に届いたか確認する。
            
        - TCPは、データを順番どおりに並べる。
            
        - TCPは、届かなかったデータを送り直す。
            
        - Webサイト閲覧、メール送信、ファイルダウンロードなどでよく使われる。
            
    - 覚えるもの：
        
        - **TCP = 確実に届ける**
            
        - **TCP = 信頼性を重視した通信プロトコル**
            
        - TCPは「届いたか確認する」「順番管理する」「再送する」。
            
-  トピック：UDP
    
    - 何を扱った：
        
        - 「UDPとは何か」を確認した。
            
    - 結論：
        
        - **UDP → User Datagram Protocol → ユーディーピー → 速さ・リアルタイム性を重視した通信プロトコル**
            
        - UDPは、ネットワークでデータを送るときのルールの1つ。
            
        - UDPは、届いたか細かく確認しない。
            
        - UDPは、順番もあまり気にしない。
            
        - UDPは、基本的に送りっぱなし。
            
        - 動画配信、音声通話、オンラインゲーム、DNS問い合わせなどで使われる。
            
    - 覚えるもの：
        
        - **UDP = 速く送る**
            
        - **UDP = 速度・リアルタイム性を重視した通信プロトコル**
            
        - UDPは「基本的に送りっぱなし」。
            
-  トピック：TCPとUDPの違い
    
    - 何を扱った：
        
        - TCPとUDPの違いを比較した。
            
    - 結論：
        
        - TCPは確実性を重視する。
            
        - UDPは速さを重視する。
            
        - TCPは届いた確認をする。
            
        - UDPは届いた確認を基本的にしない。
            
        - TCPは再送する。
            
        - UDPは基本的に再送しない。
            
        - TCPは順番管理をする。
            
        - UDPは基本的に順番管理をしない。
            
    - 覚えるもの：
        
        - **TCP = 確実に届ける**
            
        - **UDP = 速く送る**
            
        - 比較表：
            

|項目|TCP|UDP|
|---|---|---|
|重視するもの|確実性|速さ|
|届いた確認|する|基本しない|
|再送|する|基本しない|
|順番管理|する|基本しない|
|例|Web、メール、ファイル転送|動画、通話、ゲーム、DNS|
