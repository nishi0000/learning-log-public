### 1. 扱ったトピック一覧（時系列）

-  トピック：エンベロープ暗号化
    
    - 何を扱った：
        
        - 「エンベロープ暗号化ってなんですか」という質問
            
        - データ本体と鍵を分けて暗号化する方式
            
    - 結論：
        
        - エンベロープ暗号化とは、**データ本体をデータキーで暗号化し、そのデータキーをマスターキーで暗号化して保護する方式**
            
        - データを直接マスターキーで暗号化するのではなく、データ用の鍵を作り、その鍵をさらに別の鍵で守る
            
    - 覚えるもの：
        
        - **エンベロープ暗号化 = データを暗号化する鍵を、さらに別の鍵で包んで守る方式**
            
        - **エンベロープ = 封筒**
            
        - **データキーをマスターキーで包む**
            
-  トピック：データキー
    
    - 何を扱った：
        
        - エンベロープ暗号化で使う鍵の1つ
            
    - 結論：
        
        - データキーは、**実際のデータ本体を暗号化する鍵**
            
    - 覚えるもの：
        
        - **データキー = データ本体を暗号化する鍵**
            
-  トピック：マスターキー
    
    - 何を扱った：
        
        - エンベロープ暗号化で使うもう1つの鍵
            
    - 結論：
        
        - マスターキーは、**データキーを暗号化する鍵**
            
        - データ本体を直接暗号化する役割ではなく、データキーを保護する役割
            
    - 覚えるもの：
        
        - **マスターキー = データキーを暗号化する鍵**
            
-  トピック：エンベロープ暗号化の保存構成
    
    - 何を扱った：
        
        - 暗号化後に何を保存するか
            
    - 結論：
        
        - 保存するものは通常、次の2つ
            
            - 暗号化されたデータ
                
            - 暗号化されたデータキー
                
    - 覚えるもの：
        
        - **保存するのは「暗号化データ」＋「暗号化データキー」**
            
-  トピック：エンベロープ暗号化の流れ
    
    - 何を扱った：
        
        - 暗号化と復号の流れ
            
    - 結論：
        
        - 暗号化時：
            
            - データ → データキーで暗号化 → 暗号化されたデータ
                
            - データキー → マスターキーで暗号化 → 暗号化されたデータキー
                
        - 復号時：
            
            - 暗号化されたデータキー → マスターキーで復号 → データキー
                
            - 暗号化されたデータ → データキーで復号 → 元のデータ
                
    - 覚えるもの：
        
        - **暗号化：データ本体はデータキー、データキーはマスターキー**
            
        - **復号：まずマスターキーでデータキーを戻し、そのデータキーでデータ本体を戻す**
            
-  トピック：エンベロープ暗号化を使う理由
    
    - 何を扱った：
        
        - なぜ鍵を2段階に分けるのか
            
    - 結論：
        
        - 大きな理由は、**鍵の管理をしやすくするため**
            
        - ファイルごとにデータキーを作り、マスターキーはデータキーを守る役割に集中できる
            
    - 覚えるもの：
        
        - **目的 = 鍵管理をしやすくする**
            
        - **マスターキーはデータ本体ではなく、小さな鍵を守る**
            
-  トピック：AWS KMSでのエンベロープ暗号化
    
    - 何を扱った：
        
        - AWS KMSでよく出る考え方
            
    - 結論：
        
        - S3などのデータ暗号化で、エンベロープ暗号化の考え方が使われる
            
        - S3オブジェクト本体はデータキーで暗号化
            
        - データキーはKMSキーで暗号化
            
        - KMSキーがマスターキー側の役割
            
    - 覚えるもの：
        
        - **AWS KMSでは、KMSキーがマスターキー側**
            
        - **S3オブジェクト本体 → データキーで暗号化**
            
        - **データキー → KMSキーで暗号化**
