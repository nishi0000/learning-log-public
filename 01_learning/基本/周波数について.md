### 1. 扱ったトピック一覧（時系列）

-  ダウンカウンタ割込み時間
            
    - 確定した結論：
        
        - 分周：16MHz ÷ 32 = 500kHz
            
        - 500kHzの周期：1/500,000 秒 = 2μs
            
        - 150カウント分：2μs × 150 = 300μs
            
-  標本化定理とサンプリング周期
            
    - 確定した結論：
        
        - 標本化定理：サンプリング周波数 fs > 2 fmax
            
        - fmax=20kHz → fs > 40kHz
            
        - サンプリング周期 T = 1/fs → 1/40,000 秒 = 25μs（正答：25μs）
            
-  周波数・振幅の区別（音の理解）
            
    - 確定した結論：
        
        - 周波数（1秒あたりの振動回数）＝音の高さ（高音/低音）
            
        - 振幅（揺れの大きさ）＝音量（大きい/小さい）
            
-   μsとMHzの関係
            
    - 確定した結論：
        
        - 1μs = 1/1,000,000 秒
            
        - 1MHz = 1,000,000 Hz（1秒に100万回）
            
        - 周期T=1/fより、1MHzの周期は1μs
            
-  NoSQL/BASE特性（結果整合性）
            
    - 確定した結論：
        
        - BASE：BA/S/E（Basically Available / Soft State / Eventually Consistent）
        - CAP用語：
            
            - AP寄り：可用性優先＋結果整合性になりやすい
                
            - CP寄り：整合性優先で受付停止/拒否になりやすい
            
-  2相コミット（2PC）
            
    - 確定した結論：
        
        - 2PCは分散トランザクションの手順で「全員成功か全員中止」を揃える
            
        - 2段階：Prepare（準備・YES/NO・ロックして待機）→ Commit/Abort（確定/中止）
            
        - 可用性より整合性を強く守る方向になりやすい（CP寄りになりがち）

### 2. 確定した定義・式

- Hz → Hertz → ヘルツ → 周波数（1秒あたりの繰り返し回数）
    
    - 定義：周波数 = 1秒間に何回振動（繰り返し）するか
        
    - 式：f（Hz）
        
    - 関連する用語：周期T、kHz、MHz
        
- 周期
    
    - 定義：1回の繰り返しにかかる時間
        
    - 式：T = 1 / f
        
    - 関連する用語：周波数、サンプリング周期
        
- μs → microsecond → マイクロ秒 → 100万分の1秒
    
    - 定義：1μs = 1/1,000,000 秒
        
    - 式：1秒 = 1,000,000 μs
        
    - 関連する用語：MHz（逆数関係）
        
- MHz → megahertz → メガヘルツ → 100万Hz
    
    - 定義：1MHz = 1,000,000回/秒
        
    - 式：周期T = 1/f → 1MHzの周期 = 1μs
        
    - 関連する用語：μs、Hz
        
- 標本化定理（サンプリング定理）
    
    - 定義：元信号を復元するため fs > 2 fmax
        
    - 式：fs > 2 fmax、T = 1/fs
        
    - 関連する用語：サンプリング周波数、サンプリング周期
        
- BASE → Basically Available / Soft State / Eventually Consistent
    
    - 定義：
        
        - BA：基本的に利用可能（可用性優先）
            
        - S：途中状態を許容（厳密一致を常時は要求しない）
            
        - E：最終的に一致（結果整合性）
            
    - 式：なし
        
    - 関連する用語：結果整合性、CAP（AP/CP）
        
- 2PC → Two-Phase Commit → 2相コミット
    
    - 定義：分散トランザクションを全員成功/全員中止で揃える
        
    - 式：なし
        
    - 関連する用語：Prepare、Commit/Abort、ロック、CP寄り
