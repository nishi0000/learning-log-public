### 1. 扱ったトピック一覧（時系列）

-  トピック：POP3とは何か
    
    - 何を扱った：
        
        - 「POPｓ３とはなんですか」という質問
            
        - 最初は「POP3」として説明
            
    - 結論：
        
        - **POP3 → Post Office Protocol version 3 → ポップスリー → メールを受信するための通信プロトコル**
            
        - メールサーバに届いたメールを、自分のPCやスマホのメールソフトへ取り出す仕組み
            
        - POP3は、メールサーバからメールをダウンロードして読む方式
            
        - 設定によっては、メール受信後にサーバ上のメールが削除されることがある
            
    - 覚えるもの：
        
        - **POP3 = メールをサーバから取り出す受信方式**
            
        - **POP3 = Post Office Protocol version 3**
            
-  トピック：POP3とIMAPの違い
    
    - 何を扱った：
        
        - メール受信方式として、POP3とIMAPの違いを確認
            
    - 結論：
        
        - POP3：メールを端末にダウンロードして読む
            
        - IMAP：メールをサーバ上に置いたまま読む
            
    - 覚えるもの：
        
        - **POP3 = ダウンロードして読む**
            
        - **IMAP = サーバ上に置いたまま読む**
            
-  トピック：POP3Sとは何か
    
    - 何を扱った：
        
        - 「POP３ｓだった」という訂正
            
        - POP3Sの意味を確認
            
    - 結論：
        
        - **POP3S → POP3 over SSL/TLS → ポップスリーエス → POP3をSSL/TLSで暗号化したメール受信方式**
            
        - POP3Sの役割は、POP3と同じくメールサーバからメールを取り出すこと
            
        - POP3Sは、通信内容をSSL/TLSで暗号化して安全にメールを受信する
            
    - 覚えるもの：
        
        - **POP3S = POP3をSSL/TLSで暗号化したもの**
            
        - **POP3SのS = Secure**
            
        - **POP3S = 安全なPOP3**
            
-  トピック：POP3Sのポート番号
    
    - 何を扱った：
        
        - POP3とPOP3Sのポート番号
            
    - 結論：
        
        - POP3：110番ポート
            
        - POP3S：995番ポート
            
    - 覚えるもの：
        
        - **POP3 = 110**
            
        - **POP3S = 995**
