### 0. スレッド概要

- 扱ったテーマ：
    
    - 基本設計書における「IPO」の意味
        
    - IPO の内訳（Input / Process / Output）
        
    - ログイン機能を例にした IPO の整理
        
    - 基本設計書で IPO を書く目的
        
    - 現場による IPO の使われ方の違い
        

### 1. 扱ったトピック一覧（時系列）

-  トピック：基本設計書の「IPO」とは何か
    
    - 何を扱った：
        
        - ユーザーから「基本設計書のIPOってなに？？」という質問あり
            
    - 結論：
        
        - IPO は **Input / Process / Output** のこと
            
        - 意味は「何を受け取り、どう処理し、何を返すか・出力するか」を整理したもの
            
    - 覚えるもの：
        
        - **IPO → Input / Process / Output**
            
        - **Input = 入力**
            
        - **Process = 処理**
            
        - **Output = 出力**
            
-  トピック：IPO の具体例（ログイン機能）
    
    - 何を扱った：
        
        - ログイン機能を例にして IPO を説明
            
    - 結論：
        
        - Input：社員番号、パスワード
            
        - Process：入力チェック、ユーザー照合、認証判定
            
        - Output：メニュー画面表示、エラーメッセージ表示
            
    - 覚えるもの：
        
        - IPO は機能単位で「入力・処理・出力」を分けて整理する
            
        - ログイン機能の例
            
            - 入力：社員番号、パスワード
                
            - 処理：入力チェック、照合、認証判定
                
            - 出力：画面表示、エラー表示
                
-  トピック：基本設計書で IPO を書く目的
    
    - 何を扱った：
        
        - 基本設計書の中で IPO が何のために書かれるか
            
    - 結論：
        
        - 「その機能が何を入れて、どう動いて、何が出るのか」をざっくり見えるようにするために書く
            
    - 覚えるもの：
        
        - 基本設計書の IPO は、機能の全体像を整理するための枠組み
            
-  トピック：IPO の使われ方の幅
    
    - 何を扱った：
        
        - 現場によって IPO の意味合いが少し広く使われる点
            
    - 結論：
        
        - 現場によっては、画面設計の入力項目・処理概要・出力結果の整理表のような意味で広めに使われることがある
            
    - 覚えるもの：
        
        - IPO は厳密な定義だけでなく、現場では広義に使われる場合がある
