### 1. 扱ったトピック一覧（時系列）

-  トピック：IIS
    
    - 何を扱った：IIS とは何か？（WindowsのWebサーバー機能としての説明）
        
    - 結論：
        
        - IIS = Internet Information Services（読み：アイアイエス）
            
        - Windowsに用意されているWebサーバー機能。Webサイト／Webアプリ／APIをホストする用途として説明した
            
        - 関連用語として「サイト」「アプリケーションプール」「バインド」を“出てきた用語”として列挙した（詳細解説はしていない）
            
    - 覚えるもの：
        
        - IIS → Internet Information Services → アイアイエス → WindowsのWebサーバー機能
            
-  トピック：Windows Server
    
    - 何を扱った：Windows Server とは何か？（用途・位置づけ）
        
    - 結論：
        
        - Windows Server = サーバー用途向けのWindows（社内の仕組みを動かす土台という位置づけ）
            
        - 例として、ユーザー管理（Active Directory）、ファイル共有、IISでのWebサーバー、アプリ実行基盤、リモート接続（RDP）などの用途を列挙した
            
        - 対比として「Windows 10/11 = 個人の作業用」「Windows Server = みんなが使うサービス提供用」と説明した
            
    - 覚えるもの：
        
        - Windows Server → サーバー用途向けWindows →（個人PC用Windowsと役割が違う：サービス提供の土台）
