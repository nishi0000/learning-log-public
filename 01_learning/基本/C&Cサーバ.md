### 0. スレッド概要

- 扱ったテーマ：C&Cサーバ、ボットネット、マルウェア感染端末の遠隔操作の関係
    

### 1. 扱ったトピック一覧（時系列）

-  トピック：C&Cサーバ
    
    - 何を扱った：
        
        - 用語「C&Cサーバってなに？」を確認
            
        - Command and Control の意味を確認
            
    - 結論：
        
        - C&C → Command and Control → コマンド・アンド・コントロール → 命令・制御
            
        - C&Cサーバ ＝ マルウェアに感染したPCを外部から操るためのサーバ
            
        - 感染端末はC&Cサーバと通信し、命令を受ける
            
        - 命令の例として、このスレッドでは以下を確認
            
            - ファイル送信
                
            - 別のマルウェアの導入
                
            - DDoS攻撃への参加
                
        - 位置づけとして「感染した端末の司令塔」と整理
            
    - 覚えるもの：
        
        - C&C = Command and Control
            
        - C&Cサーバ = 感染端末に命令を出す本部
            
        - 「端末が外部のC&Cサーバと通信している」は危険な兆候
            
-  トピック：ボットネット
    
    - 何を扱った：
        
        - 用語「ぼっとねっとってなに？」を確認
            
        - C&Cサーバとの関係を確認
            
    - 結論：
        
        - bot → robot → ボット → 自動で命令実行する端末
            
        - ボット = マルウェアに感染して遠隔操作できる端末
            
        - ボットネット = そのボットが多数集まったもの
            
        - C&Cサーバ = その集団に命令を出す本部
            
        - 関係は以下で整理
            
            - 1台1台の感染端末 = ボット
                
            - その集団 = ボットネット
                
            - 命令を出す本部 = C&Cサーバ
                
        - 攻撃者は多数の感染端末をまとめて操り、以下を実行できると確認
            
            - DDoS攻撃
                
            - スパムメール大量送信
                
            - 情報窃取
                
            - 仮想通貨マイニング
                
        - 「ボットネットに参加している端末」= 知らないうちに他人に操られている端末、と整理
            
    - 覚えるもの：
        
        - bot = robot 由来
            
        - ボット = 遠隔操作される感染端末
            
        - ボットネット = ボットの集団
            
        - C&Cサーバ = その集団への司令本部
            
-  トピック：C&Cサーバとボットネットの関係整理
    
    - 何を扱った：
        
        - 2つの用語の対応関係を確認
            
    - 結論：
        
        - C&Cサーバ = 指令本部
            
        - ボット = 命令を受ける兵隊
            
        - ボットネット = 兵隊の集団
