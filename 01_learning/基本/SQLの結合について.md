### 1. 扱ったトピック一覧（時系列）

-  トピック：DBの内部結合と外部結合、インナージョイン／レフトジョインの違い
    
    - 何を扱った：
        
        - 「DBの内部結合と外部結合」「インナージョイント」「レフトジョイン」の違いが分かっていなかったため整理
            
        - 用語対応（日本語⇔SQLキーワード）
            
        - 具体例（users / orders）で、結果がどう変わるかを確認
            
        - LEFT JOIN で WHERE に右表条件を書くと意図が崩れる（NULL行が落ちる）点を確認
            
    - 結論：
        
        - 内部結合 = INNER JOIN：両表でキーが一致した行だけ残る（共通部分のみ）
            
        - 外部結合：一致しない行も残す結合
            
            - LEFT JOIN（左外部結合）：左表は全行残る／一致しない右表側は NULL になる
                
            - RIGHT JOIN（右外部結合）：右表は全行残る（説明として言及）
                
            - FULL OUTER JOIN（完全外部結合）：両方残す（説明として言及、DBにより未対応）
                
        - 重要な注意点：
            
            - LEFT JOIN後に `WHERE 右表カラム = 条件` を書くと、右表が NULL の行が落ちて結果的に内部結合っぽくなる
                
            - 左表を残したまま右表条件をかけたい場合、`ON` 句側に条件を置く（`ON ... AND 右表条件`）という形を示した
                
        - 「注文がないユーザーだけ」などを抽出する例として `WHERE 右表の主キー IS NULL` を示した
            
    - 覚えるもの：
        
        - 用語セット（このスレッドで扱った分）
            
            - INNER JOIN → 読み：インナージョイン → 意味：内部結合（一致した行だけ）
                
            - LEFT JOIN → 読み：レフトジョイン → 意味：左外部結合（左は全行残す／右は一致しないとNULL）
                
            - RIGHT JOIN → 読み：ライトジョイン → 意味：右外部結合（右は全行残す）※言及のみ
                
            - FULL OUTER JOIN → 読み：フルアウタージョイン → 意味：完全外部結合（両方残す）※言及のみ
                
        - 最小判断基準
            
            - 「一致しなかった行を残すか？」で選ぶ
                
                - 残さない → INNER JOIN
                    
                - 左を残す → LEFT JOIN
                    
        - 最小SQLパターン（このスレッドで出た形）
            
            - INNER JOIN基本形  
                `FROM A INNER JOIN B ON A.key = B.key`
                
            - LEFT JOIN基本形（左を残す／右が無いとNULL）  
                `FROM A LEFT JOIN B ON A.key = B.key`
                
            - LEFT JOINの“WHERE罠”（右表条件をWHEREに置くとNULL行が落ちる）
                
            - 左を残したまま右表条件をかける形  
                `ON A.key = B.key AND B.col = '条件'`
                
            - 「右が無い行」を抽出する形  
                `WHERE B.pk IS NULL`
