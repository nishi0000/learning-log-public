### 1. 扱ったトピック一覧（時系列）

-  トピック：FQDNの意味
    
    - 何を扱った：FQDNとは何か
        
    - 結論：FQDN = Fully Qualified Domain Name（完全修飾ドメイン名）。インターネット上で対象を最後まで省略せずに指定した名前（例：`www.google.com`）
        
    - 覚えるもの：
        
        - FQDN → Fully Qualified Domain Name → フル クオリファイド ドメイン ネーム → 完全修飾ドメイン名
            
        - 「省略なしの正式な名前」
            
-  トピック：FQDNとDNSの関係
    
    - 何を扱った：FQDNがDNSでどう使われるか
        
    - 結論：DNSはFQDNをもとにIPアドレスを取得する仕組み（名前 → IPアドレス）
        
    - 覚えるもの：
        
        - DNSは「名前→IPアドレス変換」
            
        - FQDNはDNSに問い合わせるときの正式な名前
            
-  トピック：FQDNの構造
    
    - 何を扱った：`www.google.com` の分解
        
    - 結論：階層構造（例：`www`（ホスト） / `google`（ドメイン） / `com`（トップレベルドメイン））
        
    - 覚えるもの：
        
        - FQDNは階層構造で表現される
            
        - 右に行くほど上位（com → google → www）
            
-  トピック：DNSポイズニングの意味
    
    - 何を扱った：DNSポイズニングとは何か（FQDNとの関係）
        
    - 結論：DNSポイズニングは、FQDNとIPアドレスの対応を不正に書き換える攻撃
        
    - 覚えるもの：
        
        - 正常：FQDN → 正しいIPアドレス
            
        - 攻撃時：FQDN → 偽のIPアドレス
            
        - DNSポイズニング = DNSの対応表を改ざんする攻撃
