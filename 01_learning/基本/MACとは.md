-  トピック：MAC の略語整理
    
    - 何を扱った：
        
        - MAC = Message Authentication Code
            
        - Message Authentication Code → メッセージ認証符号
            
    - 結論：
        
        - このスレッドで扱った MAC は Message Authentication Code のこと
            
        - 意味は「メッセージ認証符号」
            
        - 役割は「メッセージが改ざんされていないことの確認」
            
    - 覚えるもの：
        
        - MAC → Message Authentication Code → メッセージ オーセンティケーション コード → メッセージ認証符号
            
        - MAC = 改ざんチェック
            
-  トピック：MAC の動きの確認
    
    - 何を扱った：
        
        - 送信側がメッセージ本体と MAC を一緒に送る流れ
            
        - 受信側が MAC を再計算して一致確認する流れ
            
    - 結論：
        
        - 送信側はメッセージと MAC を送る
            
        - 受信側は受け取ったメッセージから MAC を再計算し、送られてきた MAC と一致するか確認する
            
        - 一致すれば改ざんされていない可能性が高い、不一致なら途中で変更された可能性がある、と整理した
            
    - 覚えるもの：
        
        - 送信：メッセージ + MAC
            
        - 受信：再計算して一致確認
            
        - 一致＝改ざんなしと判断
            
        - 不一致＝改ざんの可能性
            
-  トピック：MAC と暗号化の違い
    
    - 何を扱った：
        
        - MAC と暗号化の役割の違い
            
    - 結論：
        
        - MAC は「隠す」ためのものではない
            
        - MAC は「書き換えられていないか確かめる」ためのもの
            
        - 暗号化は「中身を読めないようにする」ためのものとして整理した
            
    - 覚えるもの：
        
        - 暗号化＝中身を読めないようにする
            
        - MAC＝改ざん確認
            
        - 「秘匿性」は MAC ではなく暗号化側の役割として区別
            
-  トピック：MAC という語の多義性
    
    - 何を扱った：
        
        - 「MAC ってなんか多くない？」という確認
            
        - 「機器の番号っぽいやつ」「Apple のパソコン」との違い
            
    - 結論：
        
        - MAC という語は文脈で意味が異なる
            
        - このスレッドでは 3種類を区別した
            
            - MAC = Message Authentication Code
                
            - MACアドレス = Media Access Control address
                
            - Mac = Apple のパソコン
                
    - 覚えるもの：
        
        - MAC は文脈依存
            
        - 単体の MAC は暗号・認証文脈ではメッセージ認証符号
            
        - MACアドレスは別物
            
        - Mac は Apple 製品名
            
-  トピック：MACアドレスの意味
    
    - 何を扱った：
        
        - MACアドレス = Media Access Control address
            
        - 機器に付く番号のようなもの、という認識の確認
            
    - 結論：
        
        - MACアドレスは、パソコンそのものではなく、ネットワーク通信をする機器・部品に付いている識別番号として整理した
            
        - 例として、パソコンの LAN ポート、Wi-Fi アダプタ、ルーターの通信部分を挙げた
            
        - 同じネットワーク内で機器を見分けるために使うものとした
            
    - 覚えるもの：
        
        - MACアドレス → Media Access Control address → メディア アクセス コントロール アドレス → ネットワーク機器の識別番号
            
        - 用途：同じネットワーク内での識別
            
-  トピック：Mac の意味
    
    - 何を扱った：
        
        - Apple のパソコンとしての Mac
            
    - 結論：
        
        - Mac は Apple の製品名
            
        - もともとは Macintosh から来ていると整理した
            
        - セキュリティ用語の MAC や MACアドレスとは別物として区別した
            
    - 覚えるもの：
        
        - Mac → Macintosh → Apple のパソコン
            
        - Message Authentication Code や MACアドレスとは無関係
            
-  トピック：試験での見分け方
    
    - 何を扱った：
        
        - 試験問題で MAC をどう見分けるか
            
    - 結論：
        
        - 「MAC を用いる」のように暗号・認証文脈で出てきたら、メッセージ認証符号として読む
            
        - 「MACアドレス」と書かれていたらネットワーク機器の識別番号
            
        - 「MacBook / Mac」なら Apple 製品
            
    - 覚えるもの：
        
        - MAC単体＋暗号・認証文脈＝メッセージ認証符号
            
        - MACアドレス＝ネットワーク
            
        - Mac＝Apple
